# Task 016: Scaffold @markommerce/frontend-demo npm package + main entry

**Status**: complete
**Depends on**: 004, 010, 015
**Retry count**: 0

## Description

Add a `package.json` to `packages/frontend-demo/` declaring `@markommerce/frontend-demo` as an npm workspace member. Set `markommerce.extension` to the demo's own `index.ts` (so the Vite scanner imports it like any other module) and `markommerce.priority: 1000` (loads after the kernel). Author `resources/js/main.ts` — the bundle's actual entry point — that imports the generated `extensions.ts` and calls `defineAllComponents()`. Author a stub `index.ts` that registers the counter (filled out in task 017).

## Context

- Workspace name: `@markommerce/frontend-demo`. `priority: 1000`.
- Declares `@markommerce/frontend` as a workspace dependency via `"@markommerce/frontend": "*"`. peerDependency on `lit`.
- `main.ts` content (deterministic — drives the production bundle). Import order matters because Vite emits stylesheet `<link>` tags in import order:
  ```ts
  // Cascade-layer baseline first — must be the very first stylesheet so layer order is established.
  import '@markommerce/frontend/css/layers.css';
  // Open Props raw tokens — unlayered, sits in the global scope.
  import 'open-props/style.css';
  // Markommerce semantic tokens (inside @layer tokens, references Open Props).
  import '@markommerce/frontend/css/tokens.css';
  // Module side-effect imports (generated by the Vite scanner plugin — registers bases + mixins).
  import './.generated/extensions';
  // Demo-local component CSS (inside @layer components).
  import '../css/components/counter.css';
  // Finally, compose mixins onto bases and define the elements.
  import { defineAllComponents } from '@markommerce/frontend';
  defineAllComponents();
  ```
- `index.ts` content for this task is a stub that exports the mixin name — task 017 wires the counter and `LabelSuffixMixin`.
- Generated file path: `packages/frontend-demo/resources/js/.generated/extensions.ts` (matches the Vite plugin default).
- **Pre-seed the placeholder:** commit an empty `resources/js/.generated/extensions.ts` containing only a header comment ("// AUTO-GENERATED — overwritten by Vite. Empty placeholder so `tsc --noEmit` resolves the `main.ts` import before the first Vite run.") plus a single `export {};` to make it a valid ES module. This avoids type-check failures in tasks that run before the first `vite build`/`vite dev`. The Vite plugin (task 011) overwrites the file on every build.
- `.generated/*.ts` content beyond the placeholder is `.gitignore`d at the package level (i.e. add a `.gitignore` rule that excludes everything except the placeholder file itself — or, simpler, gitignore the whole `.generated/` directory and commit only the placeholder via `git add -f`). The task picks whichever is cleaner.
- Resources directory layout: `packages/frontend-demo/resources/{js,css,views}/`.
